New AI chat plugin (`@tissuumaps/plugins/ai-chat`): ask a language model (OpenAI, Anthropic or Ollama) about the open project and change how it is shown, with Undo. With OpenAI and Anthropic, it can also follow skills in the Agent Skills format, compute on the data with JavaScript or Python in a sandbox, show the results on the image and as charts, and search the web if allowed.
